# DSH Mobile v1.3.0

> 本次是一个较大的功能/体验版本：无障碍执行链路、手机竖屏 UI、局域网 WebUI、语音输入与退出行为都有实质改进。

## 无障碍 / Agent 手机操作

- **本地闭环执行器**：PICK → ACT → VERIFY → RETRY 的完整闭环，支持 21 种动作原语
  （点击、滑动、滚动查找、滚动收集、长按、双击、双指缩放、拖拽、输入、按键、启动应用、
  Intent、开关切换、等待、重复、条件分支、记忆收集等），并支持 `when` 条件分支与乐观执行。
- **场景记忆**：成功的操作路径可复用，同类任务第二次执行明显更快。
- **验证提速**：verify 改走 compact 快路径（体积约为 JSON dump 的 1/7），实测单次验证约 5ms；
  并在 compact 中保留 OCR 行、图标识别名与空间推断标签。
- **OCR 链提速约 4 倍**（实测 1370–1588ms → 326–393ms）：截图节流 + 内容区域裁剪 + 单帧复用。
- **页面状态检测器**：判断页面是否真正加载完成后再唤起 loop，不再用固定 sleep 干等
  （对带 Banner 广告、进页慢的应用尤其明显）。
- **模拟人类手势**：滑动轨迹带弧度与轻微抖动，不是机械直线。
- **思考开关（fast mode）**：无障碍任务期间只在第一步思考，后续步骤不再付推理成本。
- **失败反馈优化**：冷读 504 自动放宽重试一次、加载信号分强弱，减少无效往返。

## 手机竖屏 UI

- **侧栏展开即全宽**：竖屏下展开侧栏时，侧栏占满宽度、对话流自动让位；横屏/宽屏完全不受影响。
- **设置面板窄屏重构**：导航栏改为顶部横向滑动条，内容区拿满整宽，不再出现文字逐字竖排。
- **右侧面板全屏化**：窄屏下打开「查看更改 / 代码差异」自动全屏显示，不再因为宽度不足而看不见。
- 以上三项均以**客户端插件**形式实现：不修改引擎源码、不与其他 UI 插件抢 DOM，引擎升级不会覆盖。
- **设置页图标去重**：插件、语音服务、局域网访问等行改用各自独立的图标。
- **简化设置项**：移除「试验性功能」与「无障碍功能 max+」两个开关，原能力直接常驻
  （悬浮窗、麦克风、语音服务、本地识别应用入口始终可见）。

## WebUI / 局域网

- **局域网访问 WebUI**：手机与电脑在同一网络下，用电脑浏览器直连手机里的引擎
  （内置独立端口 4090 的反向代理，在原 WebUI 基础上补齐非安全上下文所需的能力）。
- **6 位验证码**：每次开启随机生成、自动复制到剪贴板、只在应用内显示一次。
- **新增常驻通知**：局域网开启后通知栏会一直提示「局域网 WebUI 已开启」，
  并带一个「关闭」按钮 —— 避免忘记关闭、也方便随手停掉。
  关闭后代理进程会真正停止（普通模式同样有效）。

## 语音输入

- 悬浮球麦克风 → 底部语音面板：识别结果实时上屏、可手改后一键发送；
  支持 TTS 播报与离线识别兜底（可装 dsh-asr-service）。
- 修复：识别结束时悬浮窗突然收起造成的闪烁；发送后语音面板收起时的残影问题。

## 稳定性与体验

- **退出彻底化**：通知栏点「退出」后，除了停止引擎，还会结束主界面并销毁 WebView
  （释放约 380MB），同时停止局域网代理与本地推理进程，退出后不再后台耗内存/耗电。
- **AI 操作通知**：AI 连续执行无障碍操作时（第 3 步起）会发一条系统通知，
  显示「正在操作设备 · 第 N 步 · 点击/输入/滚动…」，停手 10 秒自动消失，点通知可回到 App。
- 修复 daemon 语法错误（此前该功能无法启动）、记忆污染、fast verify 污染记忆等问题。
- 检查更新（设置 → 关于 →「检查更新」）、多语言（中/英/德）、屏幕方向三态。


### 启动动画（补丁）

冷启动不再是一块空黑屏：品牌启动层（logo 淡入 + 呼吸、真实解压百分比、阶段文案），
页面首帧就绪后淡出并轻微放大，渐变进入界面；工具栏层级已修正，不会再盖住启动层。

## 已知问题

- 语音输入面板在发送瞬间，部分机型可能出现 1~2 帧残影（系统合成层现象），目前未能完全消除；
  不影响功能与输入结果。
